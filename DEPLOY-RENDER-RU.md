# AlienStageTelegram на Render

Проект распаковывается из `AlienStageTelegram-email-login.zip` в каталог `AlienStageTelegram`. Во время сборки `render-fix.cjs` исправляет серверную часть и подготавливает интерфейс с автоматическим созданием аккаунта.

## Команды Render

- Build: `unzip -o "AlienStageTelegram-email-login.zip" -d . && node render-fix.cjs && cd AlienStageTelegram && npm install --omit=dev`
- Start: `cd AlienStageTelegram && npm start`
- Health check: `/health`

## Как теперь работает аккаунт

При первом открытии сайта сервер автоматически создаёт гостевой аккаунт, устанавливает защищённую HTTP-only cookie и показывает только одно окно для выбора никнейма. Номер телефона, email и пароль не спрашиваются.

Никнейм должен быть уникальным: 3–20 символов, латинские буквы, цифры и подчёркивание. После выбора никнейма пользователь сразу попадает в приложение.

**Ограничение:** это аккаунт, привязанный к браузеру/устройству. Cookie хранится до 30 дней; при очистке cookies/данных сайта, смене браузера или устройства доступ может потеряться. Сейчас нет восстановления такого аккаунта по почте/телефону и нет безопасного переноса между устройствами. Не очищайте данные сайта, если аккаунт нужно сохранить.

Существующие аккаунты не удаляются. Новые гостевые аккаунты создаются с уникальным временным ником и получают стартовый баланс из `STARTER_TOKENS`.

## Переменные

- `DATABASE_URL` — PostgreSQL.
- `JWT_SECRET` — секрет сессии (Render генерирует его из `render.yaml`).
- `STARTER_TOKENS` — начальный баланс (по умолчанию 100).

Не публикуй JWT и не добавляй `.env` в GitHub.
