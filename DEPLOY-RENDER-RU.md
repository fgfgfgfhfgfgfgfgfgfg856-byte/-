# Публикация AlienStageTelegram на Render

Этот репозиторий хранит исходный проект в архиве `AlienStageTelegram-multiplatform (1).zip`.
Файл `render.yaml` автоматически распаковывает архив при сборке и запускает Node.js-сервер.

## Запуск

1. Открой https://dashboard.render.com/blueprints.
2. Нажми **New Blueprint Instance**.
3. Подключи репозиторий `fgfgfgfhfgfgfgfgfgfg856-byte/-`.
4. Выбери ветку `main` и подтверди создание сервиса.
5. Дождись статуса **Live**. Render покажет адрес сайта вида `https://alien-stage-telegram.onrender.com`.

## Важное ограничение бесплатного тарифа

Текущая версия проекта хранит аккаунты, сообщения и загруженные аватары в локальной SQLite-базе и папке uploads. У бесплатного Render файловая система временная: после перезапуска или нового развёртывания эти данные могут исчезнуть. Бесплатная конфигурация подходит только для проверки сайта, а не для хранения постоянных аккаунтов. Для постоянной работы нужно перенести базу на внешнюю PostgreSQL и хранение аватаров в постоянное хранилище либо использовать платный постоянный диск.

Не публикуй секрет JWT и не добавляй файл .env в GitHub. Render сам создаёт JWT_SECRET из render.yaml.
